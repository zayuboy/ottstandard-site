05 / 사용 방법

처음에는
이렇게 시작하세요.

먼저 한 문장을 읽고 저장해보세요. 필요한 기능은 아래 항목을 펼쳐 확인할 수 있습니다.

설치·시작 안내 보기 ↗

  1. 확장 프로그램 준비

    공식 사이트의 설치 안내에 따라 설치하고, 브라우저에서 OTT STANDARD를 사용할 수 있는지 확인합니다.

  2. 영상과 자막 켜기

    Netflix에 로그인해 영상을 재생합니다. 가능하면 공부할 언어의 원본 자막을 선택하세요.

  3. 내 수준에 맞추기

    학습 언어와 모드를 선택합니다. 처음에는 후리가나와 번역을 함께 켜고 읽어보세요.

  4. 문장 하나 남기기

    ‘현재 문장 저장’을 누른 뒤 저장 목록에서 확인합니다. 공부 메뉴에서는 회화·한자·이야기를 시작할 수 있습니다.

자막 · 후리가나 · 학습 모드

학습 언어를 선택하면 원문과 번역의 배치가 바뀝니다. 후리가나는 한자 위에 읽는 법을 표시하는 기능입니다. 자막 위치와 글자 크기도 조절할 수 있습니다.

학습 모드표시 방식활용 방법
초급학습 언어 + 번역뜻과 읽는 법을 함께 확인
중급학습 언어 중심번역 없이 읽고, 모르는 문장 확인
고급자막 없이 듣기먼저 듣고 대본으로 확인

자막이 어긋나거나 멈추면 자막 새로고침을 사용해보세요. 제공되는 자막과 번역 상태는 작품·언어·재생 환경에 따라 달라질 수 있습니다.

전체 대본 · 장면 이동 · 반복 재생

전체 대본에서는 회차의 문장을 따라 읽으며, 필요한 장면으로 이동하거나 현재 문장을 반복할 수 있습니다.

  • 전체 / 저장됨 / 내 단어: 회차의 대사, 저장한 문장, 관련 단어를 나누어 확인합니다.
  • 언어 보기: 일본어·한국어 단독 표시 또는 두 언어의 위아래 순서를 선택합니다.
  • 흐름 / 고정 / 집중: 문장을 따라 읽는 방식에 맞게 표시를 바꿉니다.
  • 재생 조절: 이전·다음 대사 이동, 현재 문장 반복, 재생 속도 조절을 사용합니다.
  • 대본 저장: 저장한 텍스트를 책처럼 다시 읽습니다.

대본 저장은 자막 텍스트를 위한 기능입니다. 영상을 저장하는 기능이 아니며, 장면 재생은 해당 영상 서비스에서 이루어집니다.

저장한 문장 · 단어장 · 복습 퀴즈

현재 문장 저장 버튼으로 대사를 남기고, 저장 목록에서 작품과 회차에 따라 찾아볼 수 있습니다.

  1. 저장한 문장의 뜻을 가리고 먼저 떠올려봅니다.
  2. 반복 듣기로 소리를 다시 확인합니다. 반복 횟수는 설정에서 조절합니다.
  3. 기억하고 싶은 단어를 단어장에 추가합니다.
  4. 복습 퀴즈를 풀고, 틀린 문제의 설명을 읽어봅니다.

저장한 문장이 부족하면 제공된 예문으로 퀴즈가 구성될 수 있습니다. 전체 대본·반복 듣기·단어장 등 일부 기능에는 Pro 이용 권한이 필요합니다.

생활 일본어 · 챕터 학습과 진행

공부 메뉴에서 ‘70일 생활 일본어’를 엽니다. 5개 단계에 걸친 70개 챕터를 따라 표현을 학습합니다.

  1. 학습할 단계와 챕터를 선택합니다.
  2. 네 가지 핵심 표현과 읽는 법·뜻을 확인합니다.
  3. 여덟 문제를 풀어 학습한 내용을 확인합니다.
  4. 70점 이상이면 챕터가 완료됩니다. 결과를 확인한 뒤 다음 챕터로 이어갑니다.

한 번에 끝내기 어렵다면 같은 챕터를 다시 공부해도 괜찮습니다.

한자 · 오늘의 10개와 오답 복습

공부 메뉴에서 ‘한자 2394’를 선택합니다. 글자의 뜻과 음독·훈독, 관련 단어를 확인하고 문제를 풉니다.

  • 이어서 공부하기: 진행 중인 학습을 이어갑니다.
  • 오늘의 한자 10개: 아직 배우지 않은 글자를 공부합니다.
  • 랜덤 학습: 설정한 범위에서 한자를 골라 연습합니다.
  • 틀린 한자 다시 보기: 오답으로 남은 글자를 복습합니다.
  • 한자 도감: 학습 상태나 즐겨찾기로 글자를 찾아봅니다.

진행률은 앱에서의 학습 기록입니다. 모든 글자를 오래 기억하는 데 필요한 시간은 사람마다 다릅니다.

이야기 · 읽어주기와 다음 장 자동 넘김

공부 메뉴에서 이야기를 선택한 뒤 읽기 설정을 엽니다.

  1. 원문·번역·후리가나 표시를 원하는 조합으로 켭니다.
  2. 읽기 속도를 0.7× / 1.0× / 1.4× 중에서 선택합니다.
  3. ‘다음 페이지 자동 넘김’을 켭니다.
  4. 설정을 마친 뒤 ‘읽어주기’를 누릅니다. 한 페이지를 다 읽으면 다음 장을 이어 읽습니다.

‘읽는 문장 강조’를 켜면 듣는 위치를 함께 확인할 수 있습니다. 일시정지 버튼으로 멈출 수 있고, 마지막 페이지를 읽으면 자동으로 끝납니다.

낭독 음성과 발음 품질은 기기·브라우저에 설치된 일본어 음성에 따라 달라질 수 있습니다. 소리가 나지 않으면 기기의 소리와 일본어 음성 지원을 확인하세요.

모의시험 · 급수 선택과 결과 확인

언어와 시험 종류(JLPT·JPT·TOPIK), 급수 또는 목표 점수대를 선택합니다. 저장한 문장·대본을 활용한 문제의 포함 여부를 확인하고 20문제를 풉니다.

결과와 오답 해설을 보고 다음에 복습할 표현을 고르는 데 활용하세요. 앱의 급수 추천과 점수 추정은 학습 기록과 앱 내 문제 결과를 바탕으로 하는 참고 정보입니다.

공식 시험과 문항 수·구성·시간·채점 방식이 다릅니다. 실제 시험 준비에는 해당 시험의 공식 안내와 학습 자료를 함께 활용하세요.

설정 · 학습 기록 · 커뮤니티

설정에서 기본 학습 언어, 학습 모드, 반복 듣기 횟수, 계정과 플랜을 확인합니다. 캘린더와 학습 기록에서는 이전에 공부한 내용을 돌아볼 수 있습니다.

게시판과 채팅은 다른 사용자와 공부 이야기를 나누는 공간입니다. 닉네임 등 공개되는 내용을 확인한 뒤 이용하세요.

저장한 문장 등 기기에 보관되는 데이터는 확장 프로그램 제거나 브라우저 데이터 삭제 시 사라질 수 있습니다. 계정 로그인을 모든 학습 자료의 백업이나 기기 간 동기화로 여기지 마세요. 데이터 처리에 관한 자세한 사항은 앱의 개인정보처리방침을 확인하세요.

Free · Pro 이용 안내

기본 자막과 후리가나, 학습 모드, 현재 문장 저장으로 공부 방식을 시작할 수 있습니다. 전체 대본, 반복 듣기, 단어장, 복습·모의시험 등 일부 기능은 Pro로 제공됩니다.

이용 가능한 기능은 앱의 기능 표시와 계정·플랜 화면에서 확인하세요. 요금, 무료 체험, 구독 및 취소 조건은 공식 사이트와 실제 구독 신청 화면의 최신 안내를 기준으로 합니다.
