05 / 사용 방법

첫 문장을 저장할 때까지,
차근차근 안내할게요.

처음부터 모든 기능을 익히지 않아도 괜찮습니다. 한 문장을 읽고 저장해 본 뒤, 궁금한 기능을 하나씩 펼쳐 보세요.

설치·시작 안내 보기 ↗

  1. 확장 프로그램 준비

    공식 사이트의 안내에 따라 OTT STANDARD를 설치해 주세요. 브라우저에서 확장 프로그램을 찾았다면 첫 준비는 끝났습니다.

  2. 영상과 자막 켜기

    Netflix에 로그인하고 보고 싶은 영상을 골라주세요. 공부할 언어의 원본 자막이 있으면 함께 켜 주세요.

  3. 내 수준에 맞추기

    학습 언어를 고르고 후리가나와 번역을 켜 보세요. 읽는 데 익숙해지면 내 수준에 맞게 표시를 바꿀 수 있습니다.

  4. 문장 하나 남기기

    기억하고 싶은 대사에서 ‘현재 문장 저장’을 눌러 보세요. 저장 목록에 문장이 담겼는지 확인한 뒤, 공부 메뉴도 둘러보세요.

미루·하루 목소리 설정 · 왜 필요한가요?

미루·하루 목소리 설정은 읽어주기와 소리를 듣는 학습에 사용할 음성을 준비하는 과정입니다. 글자의 뜻뿐 아니라 소리도 익히고, 문장을 반복해서 듣고 따라 말하기 위해 먼저 설정해 주세요.

앱의 목소리 설정 안내를 따라 음성을 준비한 뒤 실제로 소리가 들리는지 확인해 주세요. 소리가 들리지 않으면 PC와 브라우저의 음량·음소거 상태도 확인해 주세요.

음성 팩 이용 안내

음성 팩은 학습에 사용할 음성 자료입니다. 앱의 음성 팩 안내에서 필요한 자료와 준비 상태를 확인해 주세요. 자료 준비를 마친 다음 읽어주기 등 사용할 기능에서 소리가 정상적으로 들리는지 확인하세요.

Google에 데이터 저장 · 다른 컴퓨터에서 이어 쓰기

Google 데이터 저장 기능을 사용하면 저장한 학습 데이터를 다른 PC에서도 불러와 사용할 수 있습니다. 계정에 로그인하는 것만으로 저장과 불러오기가 완료되는 것은 아닙니다.

  1. 기존 PC의 OTT STANDARD에서 Google 데이터 저장을 진행하고 완료 상태를 확인하세요.
  2. 새 PC의 Chrome에 OTT STANDARD를 설치하세요.
  3. 같은 Google 계정으로 저장한 데이터를 불러오세요.
  4. 필요한 데이터가 옮겨졌는지 확인한 뒤 공부를 이어 가세요.

저장 대상과 불러오기 안내는 앱에서 확인해 주세요. 새 PC에서 데이터를 확인하기 전에는 기존 PC의 브라우저나 확장 프로그램 데이터를 삭제하지 마세요.

가나 레인 · 연습전 · 랭킹전

들리는 소리에 맞는 가나를 찾아, 글자가 아래 선에 닿기 전에 클릭하는 학습 게임입니다. 플레이 전에 소리가 들리는지 확인해 주세요.

  • 연습전에서는 히라가나·가타카나·랜덤과 낙하 속도를 골라 연습합니다.
  • 랭킹전에서는 기록에 도전하고 랭킹을 확인합니다.
  • 결과 화면에서는 점수, 도달 단계, 정답 수, 최대 콤보를 돌아봅니다.

세부 규칙과 참여 조건은 게임 화면의 ‘플레이 방법’에서 확인해 주세요.

게임 화면과 소개 보기 ↗
자막 · 후리가나 · 학습 모드

먼저 공부할 언어를 선택해 주세요. 원문과 번역의 배치가 바뀌고, 일본어 한자 위에는 후리가나로 읽는 법을 표시할 수 있습니다. 글자가 작거나 위치가 불편하면 크기와 위치도 조절해 보세요.

학습 모드표시 방식활용 방법
초급학습 언어 + 번역뜻과 읽는 법을 함께 확인
중급학습 언어 중심번역 없이 읽고, 모르는 문장 확인
고급자막 없이 듣기먼저 듣고 대본으로 확인

자막이 맞지 않거나 멈췄다면 ‘자막 새로고침’을 눌러 보세요. 작품과 자막 언어, 재생 환경에 따라 표시와 번역 상태는 달라질 수 있습니다.

전체 대본 · 장면 이동 · 반복 재생

다시 듣고 싶은 대사가 있다면 전체 대본을 열어 보세요. 회차의 문장을 읽으며 해당 장면으로 이동하거나, 현재 문장을 반복해 들을 수 있습니다.

  • 전체 / 저장됨 / 내 단어: 회차의 대사, 저장한 문장, 관련 단어를 나누어 확인합니다.
  • 언어 보기: 일본어·한국어 단독 표시 또는 두 언어의 위아래 순서를 선택합니다.
  • 흐름 / 고정 / 집중: 문장을 따라 읽는 방식에 맞게 표시를 바꿉니다.
  • 재생 조절: 이전·다음 대사 이동, 현재 문장 반복, 재생 속도 조절을 사용합니다.
  • 대본 저장: 저장한 텍스트를 책처럼 다시 읽습니다.

저장되는 대본은 자막 텍스트입니다. 영상은 저장되지 않으며, 장면을 다시 볼 때는 해당 영상 서비스에서 재생합니다.

저장한 문장 · 단어장 · 복습 퀴즈

마음에 든 대사는 ‘현재 문장 저장’으로 남겨 두세요. 저장 목록에서 작품과 회차별로 찾아 다시 공부할 수 있습니다.

  1. 저장한 문장의 뜻을 가리고 먼저 떠올려 보세요.
  2. 반복 듣기로 소리를 다시 들어 보세요. 반복 횟수는 설정에서 바꿀 수 있습니다.
  3. 기억하고 싶은 단어는 단어장에 추가해 주세요.
  4. 복습 퀴즈를 풀고 헷갈린 문제는 해설을 읽어 보세요.

저장한 문장이 부족하면 제공된 예문으로 퀴즈가 구성될 수 있습니다. 전체 대본·반복 듣기·단어장 등 일부 기능에는 Pro 이용 권한이 필요합니다.

생활 일본어 · 챕터 학습과 진행

공부 메뉴에서 ‘70일 생활 일본어’를 열어 주세요. 5개 단계, 70개 챕터에 담긴 생활 속 표현을 차근차근 배울 수 있습니다.

  1. 공부하고 싶은 단계와 챕터를 골라주세요.
  2. 네 가지 핵심 표현을 읽고, 읽는 법과 뜻을 함께 확인해 주세요.
  3. 여덟 문제를 풀며 방금 배운 내용을 떠올려 보세요.
  4. 70점 이상이면 챕터가 완료됩니다. 결과를 살펴보고 다음 챕터로 넘어가세요.

한 번에 익히기 어렵다면 같은 챕터를 다시 공부해도 괜찮습니다.

한자 · 오늘의 10개와 오답 복습

공부 메뉴에서 ‘한자 2394’를 열어 주세요. 글자의 뜻과 음독·훈독을 예시 단어와 함께 익힌 뒤, 문제로 확인할 수 있습니다.

  • 이어서 공부하기: 진행 중인 학습을 이어갑니다.
  • 오늘의 한자 10개: 아직 배우지 않은 글자를 공부합니다.
  • 랜덤 학습: 설정한 범위에서 한자를 골라 연습합니다.
  • 틀린 한자 다시 보기: 오답으로 남은 글자를 복습합니다.
  • 한자 도감: 학습 상태나 즐겨찾기로 글자를 찾아봅니다.

진행률은 앱에서 공부한 기록을 보여 줍니다. 익힌 글자도 다시 헷갈릴 수 있으니, 필요할 때 복습으로 돌아와 주세요.

이야기 · 읽어주기와 다음 장 자동 넘김

공부 메뉴에서 읽고 싶은 이야기를 골라주세요. 읽기 설정을 열면 표시 방법과 듣는 속도를 맞출 수 있습니다.

  1. 원문·번역·후리가나 표시를 읽기 편한 조합으로 켜 주세요.
  2. 읽기 속도를 0.7× / 1.0× / 1.4× 중에서 편한 속도를 골라주세요.
  3. ‘다음 페이지 자동 넘김’을 켜 주세요.
  4. 설정을 마쳤다면 ‘읽어주기’를 눌러 주세요. 한 장을 다 읽으면 다음 장도 이어서 읽어 줍니다.

지금 어느 문장을 듣고 있는지 궁금하다면 ‘읽는 문장 강조’를 켜 보세요. 잠시 쉬고 싶을 때는 일시정지를 누르면 됩니다. 마지막 페이지를 다 읽으면 자동으로 끝납니다.

읽어주는 목소리와 발음 품질은 기기와 브라우저의 일본어 음성에 따라 달라집니다. 소리가 나지 않으면 기기 음량과 일본어 음성 지원을 확인해 주세요.

모의시험 · 급수 선택과 결과 확인

공부할 언어와 시험 종류(JLPT·JPT·TOPIK), 급수 또는 목표 점수대를 골라주세요. 저장한 문장·대본을 활용한 문제의 포함 여부를 확인한 뒤 20문제를 풀어 보세요.

결과를 확인한 뒤에는 헷갈렸던 문제의 해설을 읽어 보세요. 다음에 복습할 표현을 찾는 데 도움이 됩니다. 급수 추천과 점수 추정은 앱의 학습 기록과 문제 풀이 결과를 바탕으로 한 참고 정보입니다.

공식 시험과 문항 수·구성·시간·채점 방식이 다릅니다. 실제 시험 준비에는 해당 시험의 공식 안내와 학습 자료를 함께 활용하세요.

설정 · 학습 기록 · 커뮤니티

설정에서 학습 언어와 모드, 반복 듣기 횟수를 편하게 맞춰 보세요. 계정과 플랜도 여기서 확인할 수 있습니다. 지난 공부가 궁금할 때는 캘린더와 학습 기록을 열어 보세요.

게시판과 채팅에서는 함께 공부하는 사람들과 이야기를 나눌 수 있습니다. 닉네임과 작성한 내용 등 다른 사람에게 보이는 정보를 확인해 주세요.

저장한 문장과 학습 기록은 사용 중인 브라우저에 보관됩니다. 확장 프로그램이나 브라우저 데이터를 삭제하면 함께 사라질 수 있습니다. 다른 PC에서 이어 쓰려면 Google 데이터 저장 기능으로 저장한 뒤 새 PC에서 불러와 주세요. 로그인만으로 저장과 불러오기가 완료되지는 않습니다. 자세한 보관 방식은 개인정보처리방침에서 확인해 주세요.

Free · Pro 이용 안내

먼저 기본 자막과 후리가나를 켜고, 마음에 남은 문장을 저장해 보세요. 전체 대본, 반복 듣기, 단어장, 복습·모의시험 등 일부 기능은 Pro에서 이용할 수 있습니다.

이용 가능한 기능은 앱의 기능 표시와 계정·플랜 화면에서 확인하세요. 요금, 무료 체험, 구독 및 취소 조건은 공식 사이트와 실제 구독 신청 화면의 최신 안내를 기준으로 합니다.
