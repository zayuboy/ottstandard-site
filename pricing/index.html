Pro로 이용하는 것은 학습 도구입니다

Pro 구독은 OTT STANDARD 확장 프로그램의 유료 학습 기능을 제공합니다. Netflix 구독이나 영상 콘텐츠 이용권은 포함되지 않으며, 영상 서비스에는 본인의 계정과 해당 서비스의 이용 조건이 적용됩니다.

문장·단어·대본 저장은 복습할 자막 텍스트를 다루는 기능입니다. 저장 위치와 외부 번역 서비스로 전송되는 정보는 개인정보처리방침에서 확인해 주세요.

신청 전에 궁금할 수 있는 것들

체험이 끝나면 자동으로 결제되나요?

네, 안내된 30일 무료 체험이 끝나면 월 단위로 자동 갱신됩니다. 체험 종료일과 다음 결제일은 신청 화면과 안내 이메일에서 확인해 주세요.

구독을 취소하거나 환불을 문의하려면요?

구독 관리 안내나 결제 영수증에 있는 링크에서 해지 방법을 확인해 주세요. 환불 조건은 환불 정책에 안내되어 있습니다. 찾기 어려우면 문의하기로 알려주세요.

계정 로그인과 학습 자료 저장은 같은 건가요?

로그인은 구독 권한을 확인하는 데 사용되며, 저장한 문장·단어와 학습 기록은 사용 중인 브라우저에 보관됩니다. 다른 PC에서 이어 쓰려면 Google 데이터 저장 기능으로 저장한 데이터를 불러와 주세요. 로그인만으로 데이터 저장과 불러오기가 완료되지는 않습니다. 브라우저나 확장 프로그램 데이터를 삭제하기 전에는 저장한 자료를 확인해 주세요.
